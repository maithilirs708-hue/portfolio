# Thiranex Internship - Task 2

## Advanced CSS3 & Responsive Architecture

This project transforms the semantic portfolio created in Task 1 into a visually styled and fully responsive multi-page portfolio website.

## Pages

- Home
- About
- Projects
- Contact

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- CSS Variables
- Media Queries
- Responsive Web Design

## Features

### CSS Grid

CSS Grid is used for:

- Skills layout
- Projects layout
- About page layout
- Contact form layout

### Flexbox

Flexbox is used for:

- Header alignment
- Navigation
- Theme control
- Project card content alignment

### Responsive Design

The website follows a mobile-first approach and adapts to:

- Mobile devices
- Tablets
- Desktop screens

### Light and Dark Mode

CSS custom properties are used to create a light and dark theme.

The Dark Mode option can be selected from the header of each page.

## Accessibility

The website continues to use semantic HTML5 elements, accessible navigation, labels for form controls, keyboard focus styles and a skip-to-content link.
